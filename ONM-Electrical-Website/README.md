# ONM Electrical Ltd

Premium domestic and commercial electrical contractor website.

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Custom Vanilla JS (Interactive cursors, reveal animations)
- Google Fonts (Oswald & Inter)

## Getting Started
To view and develop this project locally, start a local HTTP server in the root directory. 

For example, using Node.js:
```bash
npx http-server -p 3000
```
Then visit `http://localhost:3000` in your web browser.
